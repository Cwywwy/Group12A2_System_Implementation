## 5.1 最终样本与数据覆盖

最终可用样本为 8,140 个公司—年度观测，覆盖 3,265 家公司。样本框包含 3,694 家制造业公司与 10,172 个公司—年度观测（2021 年 3,165；2022 年 3,404；2023 年 3,603），年度可用观测为 2,430、2,769、2,941。年报下载覆盖率为 98.8%，MD&A 可用率为 96.7%（2021）、99.1%（2022）、99.0%（2023）。被排除的观测主要包括无法解析的 PDF、扫描件或少于 300 token 的短文本（7 条），以及巨潮未收录的北交所挂牌前年份；逐条审计结果见可复现指南的下载核对表。

## 5.3 RQ2：财务组与文本组的贡献分布

SHAP 全局解释显示，财务组与文本组的绝对贡献占比分别为 65.4% 和 34.6%。前三项全局特征为 ocf_to_assets（0.322）、revenue_growth（0.320）、readability（0.317）。对于最高排序观测 000820（2021 年，子行业 C42），融合异常分数为 0.759，M-Score 为 1,077.5，主要局部驱动因素为 receivables_turnover、revenue_growth、accruals_to_assets。这些结果说明财务特征主导融合排序，文本特征贡献有限，但并不构成因果解释或违规认定。

## 5.4 RQ3：排序稳定性

不同模型前 10% 名单的重叠程度为：财务单独与融合 0.817，财务与文本仅 0.111，说明两类信号排序出的公司差异很大。自编码器重建误差与基准的相关为 0.009（p = 0.409），前 10% 富集率为 0.994（校准口径 1.253），与随机无异，未复现主结果。分年度看排序也很稳定：财务单独的秩相关为 2021 年 0.103、2022 年 0.130、2023 年 0.173；文本单独在 3 年中有 3 年为负，且融合模型在每一年都低于财务单独模型。更换基准只改变富集率的水平，不改变模型排序，因此结论对模型选择敏感，宜作为筛查信号而非稳定风险标签。

## 5.5 讨论与局限

研究局限包括：第一，基准本身不完美，−1.78 阈值在本样本标红 62.8% 的观测，而校准口径只是相对目标，两者都无法给出干净的精确率；第二，文本度量仍是近似——情感词典为姚加权等（2021）正式版，分词后逐词匹配，每 1000 个 MD&A 词元命中 111.3 个情感词（引导版为 13.4 个，约 8.3 倍），因此否定结论并非词表过稀所致，可读性基于字符级代理，扫描件与不可读年报被排除；第三，样本限于制造业三年窗口，因此 RQ1 的否定结论应理解为该时期该行业的证据，而非关于中文披露文本的一般规律。上述选择均在可复现指南（§5）中披露，且本节所有表格都可由已发布脚本重新生成。

## 从第一版到第二版：做法改进与结果差异

本研究第一版使用自建的小规模引导词典度量 MD&A 文本，并只用 Beneish 原始阈值评估排序。在完整样本到位后发现两个设计弱点：引导词典每千词只能命中个位数的情感词，因此阴性结果容易被质疑为度量太粗；而原始阈值会标红样本中过半的观测，使所有富集率被机械地拉向 1。为避免报告一个脆弱的否定结论，我们重建了两部分设计，并在完全相同的 firm-year 样本上重跑了整条流程。

表 5.4　第一版与第二版的设定差异及其对结果的影响

| 设计选择 | 第一版（v0.1） | 第二版（v0.2） |
| --- | --- | --- |
| 情感词典 | 自建引导词表：正面 38 词 / 负面 33 词 | 姚加权等（2021）：正面 3,585 词 / 负面 1,633 词 |
| 词典匹配方式 | 原文子串计数 | jieba 分词后词元精确匹配（用户词典 5,218 词） |
| 每 1000 词元情感词命中 | 13.4 | 111.3（8.3 倍） |
| 不确定词表 | 23 词 | 约 100 词（Loughran-McDonald 与曾庆生等） |
| Beneish 基准 | 仅原文阈值 M > −1.78（标红 62.8%） | 原文阈值 + 样本前十分位校准（M > 16.52，10%） |
| 文本单独 / 融合秩相关 | -0.030 / 0.103 | -0.029 / 0.103 |
| 自编码器秩相关（p） | 0.012（p = 0.272） | 0.009（p = 0.409） |
| 文本单独前 10% 富集（校准口径） | 1.07 | 0.85 |
| RQ1 的回答 | 文本无增量价值 | 结论不变：文本无增量价值 |

表 5.4 汇总了两版设定。第二版以姚加权等（2021）完整中文金融情感词表替换引导词典，扩充不确定词表，将子串计数改为 jieba 词元精确匹配，并在单一阈值之外补充了样本前十分位的校准口径：每 1000 个 MD&A 词元命中 111.3 个情感词，第一版为 13.4 个，密度提高到 8.3 倍。核心结论并未改变：文本单独的秩相关由 -0.030 变为 -0.029，融合模型由 0.103 变为 0.103，自编码器由 0.012（p = 0.272）变为 0.009（p = 0.409）；在校准口径下，文本单独的前 10% 富集率由 1.07 降至 0.85。因此改进体现在否定结论的可靠性上，而非结论的方向——第二版消除了两个最容易被指出的度量质疑，而 RQ1 的回答依然是文本特征没有增量价值。两版设定均被保留：第一版的词典冻结文件、MD&A 文本缓存与结果表都存放在仓库中，scripts/compare_runs.py 可复现本文报告的差异。
