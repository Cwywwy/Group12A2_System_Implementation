## 二、不得出现的表述（一旦出现即视为回归）

1. 「600870 未被 Beneish 标记」——事实相反。
2. 摘要中的 AE「0.009, p = 0.409」——旧跑数；现为 −0.007（p = 0.528）。
3. 「text-only 在两个阈值都低于机会」——top-5% 为 1.10。
4. 「fused 增量在所有可区分处为负」——负号属于 text 块。
5. 「附录 A 的稳健性检验支持 RQ1 结论」——附录 A 自述只作测量核查。
6. 任何未登记的 TF-IDF 区间数字（0.63–0.81 / 0.48–0.57）。
7. 「literal Beneish」或「conventional Beneish threshold」——DEPI 已中性化，须写「修改版 / DEPI 中性化口径」。
8. 「Jaccard overlap」——实际定义为 |A∩B|/|A|。
9. 把有监督 OOF AUC（0.6723/0.5701/0.6733）当作无监督排序结果引用。
10. 把 1,731 / 9,414 / 18.39% 当作当前样本数（现为 1,686 / 9,239 / 18.25%）。

## 三、必须披露的限制（正文或附录至少一处）

- DEPI 因缺折旧费用表被中性化为 1.0，基准为修改版 Beneish。
- t+1 标签：宽松版（沿用）+ 严格版（最早宣告日晚于年报披露日）两套，主表用哪套须明示。
- 样本含北交所系列代码公司（202 家 / 408 行 / 4.4%），未按上市状态或上市日期过滤。
- 完全案例样本（10,172 → 9,239）同时约束财务单模型与文本单模型，比较为配对同一样本。
- SHAP 值为路径长度单位，方向可读，不可与 0–1 异常分相加。
- 有监督区间基于 firm-year 级 bootstrap（非 firm 级聚类），区间偏窄。
