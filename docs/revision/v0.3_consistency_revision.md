## 2. 结论边界（v0.3 起生效）

用途：约束论文正文、附录、答辩与交接文档中可以写什么、不可以写什么。

### 2.1 可以保留的结论（有当前表支撑）

| 结论 | 支撑 | 允许的写法 |
| --- | --- | --- |
| 融合 / 财务排序对修改意见有判别力，显著优于 Beneish M-Score | `event_ranking_metrics.csv`：mod_opinion finance IF AUC 0.8015 [0.7740, 0.8327]，Beneish 0.2418 | 「finance-only / fused 排序明显高于 M-Score 基准」 |
| 财务特征单独使用即已接近融合模型 | 同上：finance .8015 vs fused .7692 | 「文本未提升排序质量」 |
| 文本模型与 M-Score 几乎不相关、方向略反 | `model_metrics.csv`：if_text −0.0259（p 0.0127）；if_fused −0.0176（p 0.0915） | 「相关系数接近 0（约 −0.02～−0.03），实务上视为无关联；显著性来自样本量，不来自效应大小」 |
| 有监督增量方向为正但不可与零区分 | `event_supervised_metrics.csv` 8 个 delta 全正、CI 全含 0；严格门 6/8 为正、仍 0 个排除 0 | 「点估计为正、区间含零，不能声称有增量」 |

| SHAP 重要性分布平坦 | `shap_global.csv` 最高 0.3138、最低 0.2535；组贡献按特征平均 11.0% vs 11.3% | 「无单一主导特征，重要性分布平坦」 |
| 排名年度稳定性差、2022 之后富集回落 | `topk_metrics.csv` 与年报内 ρ（−0.004 / −0.003 / −0.031） | 「逐年重标定不能修复方向；2022 起富集低于 1」 |
| 600870 是「基准与模型同时报警」的正例 | `anomaly_scores.csv` + `event_table.csv` | 「M-Score 14.3 已高于两个阈值；该 firm-year 在 t+1 有披露类处罚，属同时命中的强正例」 |

### 2.2 不得出现的表述（出现即视为回归）

1. 「600870 未被 Beneish 标记」——事实相反。
2. 摘要中的 AE「0.009, p = 0.409」——旧跑数；现为 −0.007（p = 0.528）。
3. 「text-only 在两个阈值都低于机会」——top-5% 为 1.10。
4. 「fused 增量在所有可区分处为负」——负号属于 text 块。
5. 「附录 A 的稳健性检验支持 RQ1 结论」——附录 A 自述只作测量核查。
6. 任何未登记的 TF-IDF 区间数字（0.63–0.81 / 0.48–0.57）。
7. 「literal Beneish」或「conventional Beneish threshold」——DEPI 已中性化，须写「legacy / 修改版口径」。
8. 「Jaccard overlap」——实际定义为 \|A∩B\|/\|A\|。
9. 把有监督 OOF AUC（0.6723/0.5701/0.6733）当作无监督排序结果引用。
10. 把 1,731 / 9,414 / 18.39% 当作当前样本数（现为 1,686 / 9,239 / 18.25%）。

### 2.3 必须披露的限制（正文或附录至少一处）

- DEPI 因缺折旧费用表被中性化为 1.0，基准为修改版 Beneish。
- t+1 标签：宽松版（沿用）+ 严格版（最早宣告日晚于年报披露日）两套，主表用哪套须明示。
- 样本含北交所系列代码公司（202 家 / 408 行 / 4.4%），未按上市状态或上市日期过滤。
- 完全案例样本（10,172 → 9,239）同时约束财务单模型与文本单模型，比较为配对同一样本。
- SHAP 值为路径长度单位，方向可读，不可与 0–1 异常分相加。
- 有监督区间基于 firm-year 级 bootstrap（非 firm 级聚类），区间偏窄。
